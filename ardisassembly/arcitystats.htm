Atari 8-bit version Alternate Reality the City character stats

You can change many of these stats while the game is running in an emulator.

There are 3 different values for str, int, etc. One is your base value. Another is your effective value and goes down if you are diseased. The last is your visible value and goes up if you are deluded.
