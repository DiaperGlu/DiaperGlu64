Building the game and test programs:

  The default code in the source files expects a copy of Diaperglu in /DG6502CrossAsm/
  cd into /DG6502CrossAsm/samplescripts/EasternFront/
  to build the test program enter ../../diaperglu MakeAtari8TestEasternFrontsSubsATR.dglu
  to build the game enter ../../diaperglu MakeAtari8EasternFrontATR.dglu
  to run the test program boot the TestEasternFrontSubs.atr Atari 8 bit disk image
  to run the game boot the TestEasternFront.atr Atari 8 bit disk image


About how these files were made:

  The code is a port of the Eastern Front game files that Chris Crawford released
    on his website into the public domain. The orginal game files were written for a
    an old commercial assembler for the Atari 8 bit and have to be assembled by hand.
  This port is for the 6502 Assembler I've written to run under DiaperGlu.
  The original files from Chris' website are missing the font data file and may not
    be a 'final' version that compiles into a released version of the game.
  I've tried to stick close to the the code from the original files, but I did fix a couple
    obvious bugs and modified others to use lookup tables and alternate math routines
    that trade memory for speed. While Chris's orginal game fits into an 8k cartridge
    that runs on older computers, the newer models and the emulator have a lot more ram
    so I used more memory to speed things up.
  I'm hoping I didn't add any bugs doing the port.
 
About how the game works:

  The main program does the russian ai and turn processing.
  The vertical blank interrupt routine handles user input.
  The display list interrupt routine changes the screen colors and 
    map font while the hardware draws the screen.

Check to see if units have supply

  // German units do not have supply in spring or fall due to 'mud' and lose half their strength
  //   but... during the 32 tick movement phase armies are given back 1 or 2 points each tick
  // German units also do not have supply in winter if 
  //   4 * distance from E edge + 0x4A is < [RANDOM]
  //   Russian units all year and German units in summer do not have supply if the supply 
  //     path is blocked.
  //     The calculation for checking the supply path is a bit complicated but it
  //       boils down to this I think:
  //       The supply path is a straight line from the unit. W for Germans, E for Russians.
  //       If there is an enemy unit on the supply path, it is blocked.
  //       If a square on the path has a pair of enemy units directly to the N and S,
  //         it is blocked.
  //       If there is an unpaired enemy unit directly N or S of the square, the path
  //         tries to pass. 
  //         There are a limited number of tries to pass for the entire path.
  //         There is a 50% chance to pass. 
  //         If the pass fails, it tries again for the same square until it succeeds. 
  //         If the path runs out of tries, the path is blocked. If the path reaches 
  //           the edge of the map, it succeeds.
  //         If there is a lake it's a bit tricker... but I think it works like this:
  //         If there is a lake directly on the path with no enemy units near it,
  //           the path is not blocked.
  //         If there is a lake directly on the path with enemy units around it,
  //           the path will try to pass. The math is a bit compilicated and there are
  //           many cases, so I'll just say what it does. The math uses a point system.
  //           A lake on the square is 1 point. Units to the N S E W are 2 points.
  //           Units to the NE NW SE SW are 1 point. If there are 2 or more points for
  //           the square, the same point system is applied randomly to either the square
  //           to the N or S. If the square N or S is blocked too, a 'try' is used and
  //           N or S of the original square is randomly chosen again. This means units
  //           up to 2 squares N or S of the lake can affect whether or not the square
  //           uses a try (if there are units and lakes only on one side)
  //           or is blocked (units and lakes on both sides).
